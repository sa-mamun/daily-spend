# Kharcho mobile app

Offline-first personal expense tracker built with Expo, React Native, TypeScript and SQLite.

## Run

```bash
npm start
```

Then scan the QR code with Expo Go, or press `a` for an Android emulator.

## Included

- Dashboard with today/month totals and a 7-day chart
- Add expense with amount, category, date and note
- Predefined and custom categories
- Full expense history
- On-device SQLite persistence in `kharcho.db`
